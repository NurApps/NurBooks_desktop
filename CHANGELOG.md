# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- Избранное с синхронизацией по пользователю: серверные эндпоинты `GET/POST /favorites` и `DELETE /favorites/{book_id}` (скоуп по `userId`), менеджер `src/core/favorites.py` с офлайн-кэшем.
- Секция «Продолжить чтение» на главной странице каталога — быстрый возврат к незаконченным книгам.
- История чтения: события `read` с привязкой к пользователю, эндпоинт `GET /analytics/history`, локальное хранилище в SQLite и вкладка «История чтения» в библиотеке.
- Офлайн-кэш PDF: книги копируются в `data/pdf_cache/` и читаются без интернета.
- Автоматический вход при запуске: восстановление сессии через refreshToken или анонимный вход.
- Раздел «Аккаунт» в настройках: вход по email/паролю и выход.
- Тесты (pytest): избранное, кэш PDF, история чтения, новые эндпоинты.
- Офлайн-режим: локальный SQLite-кэш каталога книг и прогресса чтения (каталог работает без сети).
- Firebase Auth: анонимный вход и вход по email/паролю через REST (Identity Toolkit), токен в `Authorization`-заголовке.
- Разграничение закладок и прогресса чтения по пользователю (скоуп `public` для анонимов и legacy-данных).
- Линтинг и автоформатирование через ruff (`pyproject.toml`, `requirements-dev.txt`).
- Rate limiting на сервере (in-memory, скользящее окно, конфигурация через env).
- API-ключ передаётся заголовком `X-API-Key` вместо query-параметра.
- CORS закрыт по умолчанию, настраивается через `CORS_ORIGINS`.
- README, CHANGELOG, лицензия MIT, единое версионирование сервера.

### Изменено
- Версия приложения поднята до `1.4.0 Beta`.
- События аналитики теперь привязаны к пользователю (`userId`).

### Исправлено
- Загрузка настроек падала при битом ключе `enable云flare_storage` — теперь миграция и отбрасывание неизвестных ключей.
- Диалоги в настройках падали с `NameError: dlg` (лямбды ссылались на `dlg` до его создания).
- Эндпоинт `PUT /authors` требовал form-data и не принимал JSON-массив.
- Мёртвый код с несуществующим атрибутом `firebase_client._db`.
- Устаревшие предупреждения Pydantic (`data.dict()` → `model_dump()`).

### Удалено
- Мусор из репозитория: `__pycache__`, `*.pyc`, логи, устаревшие SQLite-базы, `desktop.ini`, файлы IDE.
- Устаревшие одноразовые скрипты миграции SQLite→Firestore.
- Дублирующийся workflow `installer.yml` (объединён в `main.yml`).
